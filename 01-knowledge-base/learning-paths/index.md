# Learning paths

- Newcomer to physics-informed AI: taxonomy, glossary, physical priors tutorial, evaluation tutorial.
- Machine-learning researcher entering scientific computing: PDE prerequisites, operator learning, uncertainty.
- Domain scientist entering AI: model constraints, data governance, fair comparison.
- Embodied-AI learner: perception, world models, planning, sim-to-real.
- Geoscience and remote-sensing learner: observation support, EC footprints, remote sensing datasets.
- Reproducibility contributor: metadata schemas, code records, benchmark cards, validation scripts.
