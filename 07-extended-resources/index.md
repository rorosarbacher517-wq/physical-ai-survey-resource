# 07 · Extended Resources · 扩展资源

这一目录用于收纳不适合进入 canonical paper/code/dataset/benchmark layer，但对学习、实现或复现有补充价值的资源。

建议内容包括：
- official tutorials / documentation；
- lecture notes / textbooks；
- institutional project pages；
- technical reports；
- reproducibility notes；
- community resources（需明确其证据强度低于 original paper / official docs）。

## 使用原则

1. 核心 scientific claim 仍优先引用 original paper / DOI / official institutional source。
2. Secondary resources 适合教学解释和发现资料，不单独支撑关键事实。
3. fast-moving model/version 信息统一回到 [2026-08-20 Snapshot](../01-knowledge-base/13-2026-snapshot/index.md)。
4. 与 canonical resources 重复的内容不要在这里建立第二套 metadata source of truth。

知识入口：[Knowledge Base](../01-knowledge-base/index.md)。
