# Weather & Climate AI 专题路线

## Goal

不背模型榜单，而是掌握整个 forecast system：

```text
atmospheric dynamics
→ observing system
→ DA / analysis
→ forecast backbone
→ rollout
→ ensemble/probabilistic
→ data-to-forecast
→ nowcasting/downscaling
→ extremes
→ climate/coupling
→ verification
```
