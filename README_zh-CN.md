# Physical AI Survey Resource 中文说明

本仓库面向 Physical AI 综述的可维护资源库，连接论文、代码、数据集、benchmark、教程和地学遥感专题。仓库采用 fail-closed 原则：无法核验的信息不写成确定事实，缺失许可或证据的条目进入待核验队列。

主要入口：

- `metadata/` 是人工维护的事实来源。
- `02-paper-library/`、`03-code-library/`、`04-dataset-library/` 和 `05-benchmarks-and-evaluation/` 是由元数据生成的索引。
- `06-case-studies/geoscience-remote-sensing/` 是地学、遥感和碳通量专题入口。
- `audits/` 保存阶段审计、限制和待核验事项。
