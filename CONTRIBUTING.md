# Contributing

Contributions must preserve provenance and license boundaries. Use issue templates for papers, code, datasets, benchmarks, broken links, reproduction evidence, and taxonomy proposals.

Required checks before a pull request:

- metadata validates against schemas;
- generated files are refreshed;
- internal links pass;
- no private material, secrets, paywalled PDFs, or large raw data are added;
- scientific claims are adjacent to citations or marked as repository synthesis;
- conflicts of interest are disclosed.
